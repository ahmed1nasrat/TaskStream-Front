Task Manager – Frontend (Angular)

Angular frontend for the Task Manager app built as part of the ElectroPi Full Stack .NET Developer technical task. It lets a user register/log in, and then manage projects and their tasks (create, edit, delete, filter, change status).

Tech Stack
Angular (standalone components, Angular SSR + hydration scaffolding via @angular/ssr)
Reactive Forms (ReactiveFormsModule)
Angular Router with a route guard protecting authenticated pages
HttpClient with an interceptor that attaches the JWT to outgoing requests
RxJS (forkJoin, catchError, finalize)
Project Structure
src/
  app/
    guards/            → auth.guard.ts (protects the authenticated routes)
    interceptors/       → auth.interceptor.ts (attaches JWT bearer token)
    models/              → DTOs (project, task, login, register)
    pages/
      login/
      register/
      dashboard/         → overview stats, recent projects & upcoming tasks
      projects/           → list, create/edit/delete projects
      project-detail/      → single project + its tasks
      tasks/                → all tasks, filterable by project/status/priority
    services/               → project-service, task-service, user-service
    shared/shell/             → app shell (sidebar + header layout)
  environments/
    environment.ts            → apiUrl
Pages
Login / Register — authenticate against the API, JWT is stored in localStorage.
Dashboard — summary of total projects/tasks, completion rate, recent projects, upcoming tasks.
Projects — list all projects with progress; create, edit, delete a project.
Project Detail — a single project's info and its tasks.
Tasks — all tasks across projects; filter by project/status/priority, paginated; create, edit, delete a task, toggle status.
Getting Started
Prerequisites
Node.js 18+
npm
Angular CLI (npm install -g @angular/cli)
The backend API running (see environment.ts below for the expected URL)
Install
bash
npm install
Configure the API URL

src/environments/environment.ts:

ts
export const environment = {
  apiUrl: 'https://localhost:7137/api',
};

Update this to match wherever your backend is running.

Run (development)
bash
npm start

The app will be available at http://localhost:4200.

Build
bash
npm run build
Authentication

On login/register, the API's JWT is saved to localStorage under token (and the user's name under userName). The authInterceptor attaches it as Authorization: Bearer <token> on every request, and the authGuard blocks access to the dashboard/projects/tasks routes if no token is present.

Assumptions & Design Decisions
Added a Priority field (Low/Medium/High) on tasks in addition to the required Status field, to make the task list and filtering more realistic.
Kept the UI functional and clean rather than heavily polished, per the task's scope.
Used Angular's default SSR/hydration scaffolding as generated by the CLI; the authenticated pages render client-side.
